# Languages

Full guide: `docs/i18n.md`. Shown languages: English (source of truth), Ukrainian `uk`, Polish `pl`.
Arabic `ar` is right-to-left and falls back to English until translated.

## Adding or changing a message

1. Add the key to `apps/web/src/ui/i18n/messages/en.json` (ICU MessageFormat, `{name}`
   placeholders, `plural` and `select` where text depends on a count or value).
2. Add the same key to `uk.json` and `pl.json`. A count needs **all four plural forms** in both
   languages: `one`, `few`, `many`, `other`. Add `=0` or `=1` for wording that fits only exactly 0 or
   1, because Ukrainian `one` also matches 21, 31 and so on.
3. Run `pnpm --filter @cashfold/web test`. `catalogue-complete.test.ts` names the language, key and
   rule that failed: missing or extra key, unparseable message, placeholders differing from English,
   a missing plural form, or a value identical to English (add to `IDENTICAL_ALLOWED` only for names,
   codes and words that really are the same).
4. Never put text in a component directly. `e2e/pseudo-walk.spec.ts` walks the app in the pseudo
   locale `en-XA` and fails on English that did not come through the catalogue.

## Details that bite

- Use the glossary in `specs/004-ukrainian-polish-languages/contracts/glossary.md` so one term has
  one translation everywhere.
- Error messages are `error.*` keys (English in `ui/errors/catalogue.ts` plus the language files).
  Errors never include user content or secrets.
- `core` orders names by character code on purpose (a query gives the same answer for everyone). Lists
  ordered by name are re-sorted for display with `sortedByName` (`ui/i18n/collation.ts`), so Polish
  Ł follows L and Ukrainian Ї follows І. Do not sort names for display with `<`.
- Language names are written in their own language and never translated (`LANGUAGE_NAMES`).
- The chosen language is stored on the device only (`language` in `cashfold.ui`), never synced or
  sent to the service.
- Desktop menu and start-up dialog text lives in `apps/desktop/src/main/menu-labels.ts`.
- Starter categories need a `starter.category.*` name in every language.
